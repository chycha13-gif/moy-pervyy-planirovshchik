# Мой первый планировщик

Личный планировщик доходов, расходов и платежей с локальным хранением данных.

Репозиторий: https://github.com/chycha13-gif/moy-pervyy-planirovshchik

GitHub Pages: https://chycha13-gif.github.io/moy-pervyy-planirovshchik/

Публикация GitHub Pages: ветка main, корневая папка /; файл .nojekyll отключает обработку Jekyll. Для запуска не нужны серверная часть, база данных или сборка.

При переходе с прежнего адреса Sites на GitHub Pages перенесите записи через экспорт/импорт JSON: это другой адрес и отдельное хранилище браузера.

## Установка на Android

Адрес приложения GitHub Pages: https://chycha13-gif.github.io/moy-pervyy-planirovshchik/

Прежний частный адрес Sites: https://moi-plan-rashodov.wittyspice129.chatgpt.site

## Первый запуск

1. Включите интернет и откройте ссылку в Chrome в обычном режиме.
2. Публикация GitHub Pages открывается без входа. Для прежнего частного адреса Sites при запросе авторизации войдите в аккаунт ChatGPT владельца.
3. Пройдите начальную настройку либо восстановите свой JSON через «Восстановить из копии». При открытии по новому адресу записи из другого браузера/файла автоматически не переносятся.
4. Дождитесь надписи «Готово к работе без интернета» внизу мастера или в «Настройках», в блоке «Приложение на телефоне».
5. Нажмите «Установить приложение», если кнопка появилась. Либо откройте меню Chrome ⋮ → «Добавить на главный экран» / «Установить приложение» и подтвердите действие. Названия зависят от версии Chrome.
6. Запускайте планировщик появившимся значком. Если Chrome предлагает только ярлык, отметьте это в результате проверки телефона: фактический диалог установки нельзя подтвердить настольной эмуляцией.

## Проверка на TECNO Camon 30 / Android 16

1. Добавьте неоплаченный расход «Проверка PWA», 100 ₽, с сегодняшним сроком. Выберите «Чернильный атлас».
2. Убедитесь, что появилась надпись готовности к работе без интернета.
3. Закройте окно приложения и вкладки планировщика в Chrome, уберите приложение/Chrome из последних приложений.
4. Включите авиарежим, отдельно выключите Wi-Fi. Откройте планировщик значком.
5. Проверьте оформление, тему, тестовый расход, ввод с экранной клавиатурой и сохранение ещё одной тестовой записи.
6. Не включая сеть, в «Настройках» скачайте резервную копию JSON. Проверьте, что файл появился в загрузках телефона. Затем выберите его через «Восстановить из копии», проверьте сводку и подтвердите замену. Копия полностью заменяет журнал состоянием на момент экспорта.
7. Ещё раз закройте и откройте приложение без сети. Записи и тема должны остаться.
8. Сообщите результат, версию Chrome и что именно предложил системный диалог установки. Тестовые неоплаченные расходы после проверки можно отменить в их карточках.

## Данные и обновления

Финансовые записи находятся только в localStorage вашего браузера. На хостинг отправляются файлы приложения, а не доходы, расходы или копии журнала. На другом устройстве или по другому адресу будет отдельное хранилище. Для переноса используйте JSON-копию; перед очисткой данных браузера обязательно сохраните её.

Интернет нужен для первого открытия, входа на частный сайт и получения новых версий. Полностью подготовленная версия работает без сети. Установка сама по себе не заменяет проверку готовности offline.

Если приложение сообщает, что офлайн-файлы сохранены не полностью, включите интернет и в «Настройках» нажмите «Подготовить офлайн-версию». Приложение проверит комплект файлов и восстановит их без очистки журнала. Если на сайте уже новый выпуск, сохраните поля, закройте все окна планировщика и откройте его с сетью, затем дождитесь готовности.

Проверка обновлений находится в «Настройках». При совпадении с версией сайта появляется «Установлена актуальная версия». Если проверка не удалась, включите сеть и повторите её; сообщение о готовом обновлении появляется только после загрузки файлов нового выпуска. Если новая версия готова, сначала сохраните поля, затем закройте все окна планировщика. Новая версия применится при следующем запуске. Открытая форма принудительно не перезагружается; обновление не очищает финансовые записи.

## Файлы проекта

Основные исходники: index.html, style.css, script.js. PWA: pwa.js, sw.js, manifest.webmanifest и три PNG в icons/. В sw.js при каждом изменении кешируемых файлов необходимо менять VERSION.

В pwa-site/ находится отдельная копия статической поставки и служебный Git-каталог публикации Sites. Этот каталог исключён из основного Git через .gitignore; перед следующей публикацией его dist/ нужно синхронизировать с основными исходниками. Идентификатор сайта хранится в pwa-site/.openai/hosting.json. Повторно создавать сайт не нужно.

Хронология и результаты проверок — в plan.md. Актуальное согласованное изменение требований к PWA — в начале tz.md, версия 1.1. Финансовая модель и ключи хранения от локальной версии сохранены.
